A top-down stealth escape game for the [Make the best turkey escape game](https://make.fun/bounty/turkey-run-game-01) bounty on make.fun.

One turkey. One farmer. One very hot oven. Sneak past the farmer's patrol, dodge the carving knife, grab three golden corn cobs, and reach the forest gate before you become Thanksgiving dinner.

- Play: open `game/index.html` in a desktop browser (or `node serve.ts`, then http://localhost:8080). Move with WASD or arrow keys, dash with Space. No network needed.
- Entry program: `node main.ts` copies `game/` and `screenshots/` to `/output` and writes `dossier.json`.
